# Banking System

A simple C-based banking system module for performing basic account transactions. Users can deposit money, withdraw funds, and check their account balance using an account number.

### Features

* Deposit money into an account
* Withdraw money with balance validation
* Check account holder and balance
* Handles invalid or non-existent accounts
* Prevents withdrawals when the balance is insufficient

### Concepts Used

C Structures, Arrays, Functions, Loops, Conditional Statements, User Input, and Basic Financial Calculations.
